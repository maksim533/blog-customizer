# Blog Customizer

![Фото проекта](./src/images/project-image.png)
Интерактивное веб-приложение для настройки внешнего вида блогов и статей с возможностью изменения шрифтов, цветов, размеров и других параметров отображения контента.

## 🚀 Функциональность

### Основные возможности:
- **Настройка шрифтов**: Выбор из 5 различных шрифтов (Open Sans, Ubuntu, Cormorant Garamond, Days One, Merriweather)
- **Размер текста**: 3 варианта размера (18px, 25px, 38px)
- **Цветовая схема**: 9 цветов для текста и фона
- **Ширина контента**: Настройка ширины контейнера (широкая/узкая)
- **Интерактивная панель**: Выдвижная боковая панель с настройками
- **Предварительный просмотр**: Мгновенное применение изменений к статье

### Компоненты:
- **Article**: Отображение статьи с примененными настройками
- **ArticleParamsForm**: Интерактивная форма настройки параметров
- **UI компоненты**: Переиспользуемые компоненты (Button, Select, RadioGroup, Text, ArrowButton, Separator)

## 🚀 Установка и запуск

### Предварительные требования:
- Node.js (версия 16 или выше)
- npm или yarn

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm start
```
Приложение будет доступно по адресу: `http://localhost:8080`

### Сборка для продакшена:
```bash
npm run build
```
Собранные файлы будут находиться в папке `dist/`

### Запуск Storybook:
```bash
npm run storybook
```
Storybook будет доступен по адресу: `http://localhost:6006`

### Сборка Storybook:
```bash
npm run build-storybook
```
